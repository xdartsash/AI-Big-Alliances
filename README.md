# AI-Big-Alliances

VERSION 2.4 — FULL VERSION IMPROVEMENTS

The improvements below require the Full version with a modified game.jar. They are not included in the gameValues-only Workshop Lite version.

• Improved loading performance for large maps, especially on HDDs.
• Added a map file cache that speeds up subsequent loads.
• Reduced microstutters at the end of a turn by spreading map display updates across frames.
• Adjusted background turn-processing priorities for smoother map movement.
• Eliminated unnecessary exceptions when accessing building attributes.
• Added smarter ally selection based on shared threats, proximity, diplomatic relations, and usefulness to the alliance.
• The AI also considers compatibility with existing members and the risk of being drawn into unrelated wars.
• The AI can send up to three alliance invitations per selection cycle by default, when suitable candidates, alliance slots, and diplomatic points are available.
• Added Smart alliance invitations: On / Off to the pre-game settings.
• Added AI support: On / Off and Support frequency: Normal / Frequent.
• Support frequency becomes greyed out and unavailable when AI support is disabled. The selected frequency is remembered.
• Updated the AI support controls in the Mod Menu and matched the new pre-game controls to the surrounding settings.
• Each campaign now stores its own smart invitation, AI support, and support frequency settings.
• Added compatibility with older saves.
• Added optional performance diagnostics that can be disabled without disabling optimizations or AI features.

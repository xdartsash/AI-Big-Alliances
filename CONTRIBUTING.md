# Contributing

Please specify whether your report or proposal concerns Workshop Lite (gameValues only), Full (modified game.jar), or both.

## Reporting a problem

Include the game version, mod version, edition, steps to reproduce, expected and actual behavior, and relevant logs. For alliance AI issues, describe the initial diplomatic situation, involved states and observed decisions. Remove credentials and personal information before posting.

## Submitting changes

1. Create a branch from main.
2. Keep changes focused and document edition-specific behavior.
3. Include reproducible validation steps and actual results.
4. Open a pull request for review.

Only submit files you are authorized to share. Do not include proprietary binaries or credentials. The repository does not currently declare a project-wide license.

Existing releases and tags must not be modified as part of documentation changes.

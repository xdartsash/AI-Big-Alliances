# Development roadmap

Proposed goals only. These items do not describe confirmed features of any existing release.

## Foundation

- [ ] Document supported game versions and edition requirements.
- [ ] Record the gameValues settings used by Workshop Lite.
- [ ] Document Full edition installation and rollback instructions.
- [ ] Publish original source code or patches where redistribution is permitted.

## Alliance AI proposals

- [ ] Evaluate potential partners using diplomatic relations, common threats and relative strength.
- [ ] Balance alliance growth and discourage repeated join/leave cycles.
- [ ] Evaluate coordination between alliance members.
- [ ] Separate gameValues-only proposals from changes requiring game.jar.

## Validation

- [ ] Compare AI decisions against an unmodified baseline.
- [ ] Test small and large alliances, neutral states and dominant coalitions.
- [ ] Record reproducible starting conditions, alliance sizes and membership changes.
- [ ] Check simulation performance and save compatibility.
- [ ] Document confirmed results and known limitations before future releases.

Existing releases are not changed by this roadmap.
